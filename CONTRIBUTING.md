# Contributing to StudyMatch

Thanks for your interest. StudyMatch is maintained by a small student team, so clear, focused contributions help most.

## Reporting bugs and ideas

- **Bug:** open an issue with the *Bug report* template. Say what you did, what you expected, and what happened instead.
- **Idea:** open an issue with the *Feature request* template and describe the problem it solves for students.
- **Security problem:** don't open an issue; follow [`SECURITY.md`](SECURITY.md).
- **University pilot:** use the *Pilot inquiry* template.

## Making a change

1. Fork the repository and create a branch from `main`.
2. Run the app locally (see [`docs/DEPLOYMENT.md`](docs/DEPLOYMENT.md)) and check your change in the browser, at desktop and phone widths.
3. Follow [`Design.md`](Design.md) for anything in `ui/`.
4. Don't commit secrets (`.env` files, API keys, OAuth credentials) or rows added to `data/studymatch.db` by local sign-ups.
5. Open a pull request using the template, and describe how you tested it.
