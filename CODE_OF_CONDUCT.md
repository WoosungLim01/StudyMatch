# Code of conduct

StudyMatch exists to help students study together, and we want working on it to feel the same way.

We follow the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). In short:

- Be respectful and welcoming, whatever someone's background or experience.
- Give and accept feedback about the work, not the person.
- No harassment, insults, or sharing anyone's private information.

If something happens that breaks these rules, contact a maintainer listed in the README's Team section privately. Maintainers may remove comments, code or contributors that don't follow this code.
