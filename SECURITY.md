# Security policy

StudyMatch stores student names, emails and survey answers, so we take reports seriously.

## Reporting a problem

Please **don't open a public issue** for a security problem. Instead, use GitHub's private reporting:

1. Go to the repository's **Security** tab.
2. Click **Report a vulnerability**.
3. Describe what you found and how to reproduce it.

Only the maintainers can see the report. We aim to reply within a week.

## Scope

- The app code in this repository.
- The deployed app at https://studymatch-8qih.onrender.com. Please test only with accounts you create yourself, and don't read, change or delete other people's data.

## Supported versions

Only the latest release and the `main` branch get fixes.
